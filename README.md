# AI RAG Chatbot

This project is a Retrieval-Augmented Generation (RAG) chatbot built using Streamlit, ChromaDB, and Sentence Transformers.

The chatbot allows users to upload PDF documents and ask questions about the content. It retrieves relevant sections from the document and uses a language model to generate answers.

## Features

- Upload PDF documents
- Automatic text chunking
- Embedding generation using Sentence Transformers
- Vector storage with ChromaDB
- Semantic search over documents
- AI-generated answers using OpenRouter models
- Simple chat interface with Streamlit

## Tech Stack

- Python
- Streamlit
- ChromaDB
- Sentence Transformers
- OpenRouter API
- PyPDF
